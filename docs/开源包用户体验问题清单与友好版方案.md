## 二、证据链

- U-02 因果（最强证据）：
  - `Setup.tsx:159` `invoke('setup_add_account', …)` → 后端 `commands.rs:1199` `persist_config(&cfg)` 写盘成功；
  - `Setup.tsx:224-226` `final = { ...draft, general: {first_run_completed:true} }`，`draft` 来自挂载时的 `stored`（旧配置）；
  - `Setup.tsx:243` `invoke('update_config', {newConfig: final})` → `commands.rs:284` `persist_config(&new_config)` 整体覆盖 → 账号消失；
  - 现有单测 `setup_wizard_add_account_logic`（commands.rs:3871）只测后端纯函数，**没有覆盖"前端 draft 覆盖"这条路径**，所以之前一直没暴露。
- U-01：`external.ts:14` 空串 + `Setup.tsx:549-556` 无 `if (URL)` 守卫。
- U-03：`Pool.tsx` 表单字段清单 vs `Sessions.tsx:592/737/474` 端口文案。
- U-05：`Setup.tsx:126-129` 早退 + `:135` 空 catch；dev server（`HAS_TAURI=false`）实测页面停在"加载中"。

## 三、"用户友好版"修复方案（下一轮执行）

### P0-1 修 U-02（账号丢失）——二选一
- **方案 A（推荐，最小改动）**：`setup_add_account` 成功后，让后端把新配置同步回前端 store。
  - `setup_add_account` 后端在写盘后发一个 `config-changed` 事件（或返回完整 cfg 让前端 `setStored`）；前端 `next()` 拿到返回的账号列表，把新账号合并进 `draft.pool.accounts`（及 `selected_id`），后续 `finish()` 的 `final` 就带账号。
  - 关键：`finish()` 的 `final.pool` 必须以**当前磁盘/内存配置**为准，而不是启动快照。
- **方案 B（重构）**：`finish()` 不再整体 `update_config`，改为逐段 update（只写 general/platform/capture/bot 等向导真正改的段），`pool` 段完全不碰。
  - 更稳，但改动面大，需回归向导所有步骤。
- 验证：向导添加测试账号 → 完成 → 打开号池应看到该账号（无需重新添加）；重开程序账号仍在；`config.toml` 含 `[[pool.accounts]]`。

### P1-1 修 U-03（端口文案）
- 会话页 `Sessions.tsx:592` 改为"每个账号独立运行，最多 8 个；添加后点开浏览器即可"，删"端口"；
- `:737-739` 列表列改为"运行状态 / 数据目录"（端口收进 hover title 或高级信息）；
- `:474` toast 去掉"（端口 63504）"，只显示"已添加 XXX → 会话 N"；
- 玩家全程不接触"端口/profile/CDP"这类词，除非开启"开发者模式"。

### P1-2 修 U-04（流程割裂）
- 号池添加账号成功后，提供显式引导："已添加，去【多开会话】一键建会话"按钮，或直接在号池保存后自动建会话（需评估与 slot1 的关系）；
- 向导里第 1 个账号必须确认已落到 `pool.selected_id` 并驱动 slot1，避免"加号却没会话"。

### P2-1 修 U-01（图标残留）
- `Setup.tsx` 的 GitHub/Discord 按钮改为条件渲染：`{AOGARA_XXX_URL && <Button …/>}`；四个空常量则该按钮整块不显示。
- 欢迎页 `links_label` 也要注意：若两个按钮都隐藏，标签文字一并隐藏。

### P2-2 修 U-05（卡死）
- `Setup.tsx` 的 `get_config` catch 里 `setErr` 提示"配置读取失败"，并提供"使用默认配置继续"按钮（用 `AppConfig::default` 等价的前端默认值）；
- `draft` 为 null 时渲染错误卡片 + 重试，而不是无限"加载中"。

### 不修复（保留现状，属设计）
- 后端 `create_session` 自动分配端口本身正确，不改分配逻辑；
- 号池账号密码明文存 `config.toml` 是现有设计（隐私提示已在向导/号池给出），本轮不动。

## 四、验收标准（下一轮修复后）

1. 全新解压 → 向导第一页无 Discord 图标；
2. 向导填账号 → 完成 → 号池立即可见该账号，重开程序仍在（U-02 闭环）；
3. 普通账号添加流程全程不出现"端口/profile/CDP"字样；
4. 号池加号后能一步到位建会话（或有清晰引导）；
5. `get_config` 失败时向导给出可操作提示，不卡死；
6. 全部用测试账号 `user@example.com` 走通，测试数据不入库、不写公开文档。
