## 四、维护规则

1. **新增文档先放 `docs/`**，并在本索引登记角色。
2. **被取代的文档移入 `docs/archive/<YYYY-MM-DD>/`**，保留原文；顶部加「历史归档」提示。
3. **不并行维护两份「当前文档」**：同一主题只允许一份主文档。
4. 主文档与源码不一致时：以源码为准，先修文档，再改代码。
5. 归档目录只增不改；需要修正历史结论时，在新主文档里写明「旧结论已被推翻」，不要回写归档原文。
