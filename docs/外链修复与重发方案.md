## 2. 风险与回滚

- **前端 build 不影响 Rust 逻辑**：只改一个字符串常量，编译失败概率低；失败则回退该行为空串重编。
- **旧 exe 备份**：替换生产 exe 前 `cp` 为 `aogara.pre-externallink.exe`。
- **zip 哈希必变**：新 exe 进包 → SHA256 与旧不同，必须替换 Release 附件（不能沿用旧哈希）。
- **Release 附件替换**：GitHub 网页删旧资产再上传新资产；上传慢（85 MB，之前卡在 20%），给用户留手动兜底。
- **tag 不动**：v1.1.0 已发布且指向 `4dc3d13`，本轮只追加 main commit，避免影响已发布 tag。

## 3. 验收标准

1. `external.ts` 四个常量：一个为仓库 URL，三个为空串。
2. 新 exe 含 `https://github.com/xiaotensai/Aogara`；新 zip 干净性/可用性全过。
3. `F:\aogara-release` main 已推送新 commit。
4. Release v1.1.0 的 zip SHA256 与新本地包一致，README/说明不变。
